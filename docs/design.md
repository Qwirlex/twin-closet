# Twin Closet — дизайн-система

Макеты: https://claude.ai/artifact/8oMisaLBUdSW47tb7C3jYp (приватная ссылка).
Стиль: **мягкий необрутализм, модный мудборд** — светлый розоватый фон, чёрные обводки 2px, жёсткие тени
со смещением, вещи на пастельных плашках, наклейки и полароиды слегка повёрнуты. Подобрано через ui-ux-pro-max
(стили Neubrutalism / Bauhaus mobile, палитра «Wardrobe & Outfit Planner: fashion rose»).
Интерфейс на английском (судьи международные).

## Цвета (токены)

| Токен | Hex | Где |
|---|---|---|
| `bg` | `#FFF3F7` | фон экранов |
| `surface` | `#FFFFFF` | карточки, нижнее меню, вторичные кнопки |
| `ink` | `#141218` | текст, обводки, тени, активная вкладка |
| `muted` | `#4D4856` | вторичный текст (≥ 8:1 на `bg`) |
| `rose` | `#C2185B` | главное действие (Buy, Rescan), акцентные цифры; белый текст 6.5:1 |
| `cobalt` | `#2A44D4` | инфо-блоки (Add more clothes, resale); белый текст |
| `sun` | `#FFC83D` | «у тебя уже есть похожее», счётчики-наклейки; текст `ink` |
| `on-cobalt-muted` | `#E3E7FF` | вторичный текст на `cobalt` |
| пастели плашек | `#CBB8FF` `#B8D8FF` `#9EE6C4` `#FFE28A` `#FFB59E` | фон под вещами, фото ракурсов, фон рендера |

## Форма

- Обводка: `2px solid ink` у всех карточек, кнопок, плашек.
- Тень: `4px 4px 0 ink` (карточки, главные кнопки), `3px 3px 0 ink` (мелкие), `5px 5px 0` — рендер примерки.
  Нажатие: сдвиг на 2px вправо-вниз и тень 0 (без анимации размеров).
- Радиусы: карточки 20–22, плашки вещей 18, полароиды 14 (фото внутри 8), кнопки и чипсы — пилюли 999.
- Повороты: только у наклеек (±3–8°) и полароидов/карточек образов (±1.5–2.5°). Списки и кнопки — ровно.

## Шрифт

**Outfit** (Google Fonts, 400–900).
- Заголовок экрана: 52/0.92, 900, UPPERCASE, `letter-spacing: -0.03em`.
- Подзаголовок блока: 16–19, 900, UPPERCASE.
- Текст: 14–16, 500; подписи вещей 13, 700; вкладки 12, 700/800.

## Компоненты

- **Нижнее меню**: белая плашка 68px, обводка + тень, 4 вкладки (Closet, Me, Try on, Looks);
  активная — чёрная пилюля с белым текстом.
- **Чипсы фильтров/ракурсов**: пилюли 44px; активная — `ink` с белым текстом.
- **Плашка вещи**: пастельный фон, вырезка вещи по центру, подпись под плашкой; наклейка NEW (`rose`).
- **«Уже есть похожее»**: блок `sun`, повёрнут −1°, справа миниатюры своих вещей.
- **Иконки**: обводка 2.2px, 22–26px, один стиль (контур).

## Доступность

- Касания ≥ 44px; иконки-кнопки с `accessibilityLabel`.
- Контраст текста ≥ 4.5:1 (проверено для пар выше).
- Повороты и тени — декор, смысл всегда в тексте.
- Анимации (позже): 150–300 мс, уважать «уменьшить движение».
