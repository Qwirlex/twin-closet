# Twin Closet — дизайн-система «Noir»

Макеты: https://claude.ai/artifact/8oMisaLBUdSW47tb7C3jYp (приватная ссылка): верхний ряд — тёмная тема
(по умолчанию), нижний — светлая; оба ряда из одного кода, тема — параметр.

Стиль: **тёмная роскошь, фото важнее интерфейса** — почти чёрный фон, рендер на весь верх экрана,
стеклянные (размытые) кнопки поверх фото, один приглушённый золотой акцент, тонкие линии вместо теней.
Выбран пользователем из трёх спокойных вариантов (A Atelier / **B Noir** / C Maison) после отказа
от яркого необрутализма («слишком ярко, детский»).

Референсы: Alta (вещи на нейтральных плашках, подпись «название / детали», примерка на спокойном фоне),
Whering (круглые категории с фото вещи, подчёркнутые вкладки). Doppl (Google) не умеет обувь —
у нас обувь есть, это стоит показать в демо.

## Темы

Переключатель: **Me › Appearance** (Dark / Light / System), плюс быстрая кнопка солнце/луна в шапке.
По умолчанию — Dark. В коде — один набор семантических токенов на тему, компоненты берут только токены.

| Токен | Dark | Light | Где |
|---|---|---|---|
| `bg` | `#0B0B0C` | `#F7F7F5` | фон экрана |
| `surface` | `#141416` | `#FFFFFF` | карточки, строки, кнопки-иконки |
| `surface2` | `#1C1C1F` | `#EFEEEC` | плашки вещей, активная вкладка, фон сегментов |
| `render` | `#1A1A1C` | `#E9E7E3` | фон под рендером примерки |
| `line` | `#2A2A2D` | `#E2E0DC` | обводки 1px, разделители |
| `text` | `#F5F5F4` | `#0C0A09` | основной текст и иконки |
| `muted` | `#A8A29E` | `#57534E` | вторичный текст (≥ 7:1 к фону) |
| `accent` | `#C8B68A` | `#7A6638` | только: метки «Already in your closet», NEW, точка статуса, иконки источников, прогресс |
| `ctaBg` / `ctaText` | `#F5F5F4` / `#0B0B0C` | `#0C0A09` / `#F7F7F5` | главная кнопка, активный сегмент |
| `glass` | `rgba(20,20,22,.55)` + blur 16 | `rgba(255,255,255,.72)` + blur 16 | кнопки поверх фото |
| `bar` | `rgba(22,22,24,.86)` + blur 18 | `rgba(255,255,255,.86)` + blur 18 | нижнее меню |

Камера скана всегда тёмная (это видео), тематизируется только нижняя панель.

## Шрифт

**Inter Tight** 300–600.
- Заголовок экрана: 36/1, 400, `letter-spacing: -0.03em`.
- Крупная цифра (счётчик скана): 64, 300.
- Метки: 11–12, 500–600, UPPERCASE, `letter-spacing: 0.14em`, цвет `muted` или `accent`.
- Текст: 14–15, 400–500; подписи вещей 14/500 + 12 `muted`.

## Форма и компоненты

- Радиусы: экраны 44, карточки 18–24, плашки вещей 18, кнопки и сегменты — пилюли 999.
- Обводка 1px `line`; теней нет (глубина — стекло и тон поверхности).
- **Нижнее меню**: плавающая стеклянная плашка 68px, радиус 34; активная вкладка — `surface2` + `text`, остальные `muted`.
- **Категории**: круги 58px с фото вещи, активный — обводка `text`.
- **Плашка вещи**: `surface2`, 168px, вещь по центру; подпись две строки.
- **Рендер примерки**: на весь верх (≈ 516px), сверху стеклянные «назад / Look N of 3 ‹ › / сохранить»,
  снизу стеклянный сегмент ракурсов Front · 3/4 · Side · Back.
- **«Already in your closet»**: карточка `surface` с меткой `accent` и миниатюрами своих вещей внахлёст.
- **Части образа**: три плитки с меткой NEW (`accent`) или YOURS (обводка).
- Иконки: контур 1.6px, 20–22px, один стиль.

## Доступность

- Касания ≥ 44px (проверено на всех экранах), иконки-кнопки с подписью для экранного диктора.
- Контраст текста ≥ 4.5:1 в обеих темах (`muted` ≥ 7:1, `accent` как текст ≥ 5.5:1).
- Выбор темы — `radiogroup`; выбранные вкладки и ракурсы помечены `aria-pressed` / `aria-current`.
- Анимации (позже): 150–300 мс, при «уменьшить движение» — без размытия и сдвигов.
