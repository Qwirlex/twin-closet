# Спека: черновик демо-видео кодом (без ключа)

Сценарий и правила — `docs/demo-video.md`. Пользователь 29.10: «начинай с 1-го и так пока всё не сделаешь» — пункт 4,
черновик видео. Финальная сборка — день 9 (3.11), из настоящих записей и ответов моделей.

## Зачем черновик сейчас
- В последний день останется подложить записи и перерендерить, а не писать видео с нуля под дедлайн.
- Уже сейчас видно хронометраж (лимит правил — **3:00**, цель 2:40–2:50), голос, титры и стиль Noir — пользователь
  может поправить текст и темп заранее.

## Честность (главное правило)
- Модельных результатов ещё нет: демо-аккаунт показывает картинки, сгенерированные для макетов. В черновике
  **нет ни одного кадра, выдающего их за ответ Muse Image или SAM**. Где нужен настоящий результат — карточка
  «Footage needed: 04-try-on.mp4 — что снять» (по таблице §2 в demo-video.md).
- Записи экрана, которые честны уже сейчас: настоящие экраны без «результатов моделей» — вход судьи и
  панель на компьютере (`07-web-judges`), посадка по зонам и замер любимой вещи рулеткой (`08-fit`; расчёт —
  наш код, таблица размеров демо-джинсов помечена в кадре как demo).
- На каждом кадре черновика — плашка **DRAFT** в углу. Финальный рендер (`npm run final`) отказывается собираться,
  пока не хватает хоть одной записи.
- Muse Voice Transcribe в приложении пока заглушка → в голосе черновика нет фразы «Twin слышит тебя»; вернём,
  когда голосовой ввод заработает.

## Что меняем в сценарии (§3–4 demo-video.md)
- Новая сцена **«Will it fit?»** после «у тебя уже есть похожее»: посадка — главная проблема продукта
  (PLAN 1.2), без неё видео про примерку неполное. Сравнение с любимой вещью по зонам: талия, бёдра, бедро, длина.
- Стили и тренды — одной фразой в сцене Twin (образы «в твоём стиле и по трендам недели»).
- Магазины: Zara, Bershka, Pull&Bear… — строкой в сцене «в магазине».
- Хук без нарисованных экранов: только типографика на чёрном.

## Как устроено — `demo/` (отдельный проект, не воркспейс)
- **Remotion** (видео как React-код, рендер в MP4 через headless Chrome): 1920×1080, 30 к/с.
- `src/script.ts` — единственный источник: сцены по порядку (id, заголовок, плашки моделей, запись или карточка
  «нужна запись», абзац голоса). Длина сцены = длина её абзаца голоса + пауза; итог проверяется (≤ 2:55 с запасом).
- Компоненты: логотип (вешалка рисуется линией: белый крючок и плечо, потом золотое; вордмарк Twin 600 / Closet 300),
  титр сцены слева, телефон в тонкой рамке по центру (видео или карточка), плашки моделей справа (стекло),
  субтитры снизу (по словам абзаца, ровно по времени), схема «How it works», финал со ссылками.
- Голос: `scripts/voice.mjs` — edge-tts (нейроголос Microsoft, бесплатно), абзац → `public/voice/NN.mp3`,
  длительности ffprobe → `public/voice/durations.json`. Есть `demo/voice.m4a` (своя запись) — позже режем её.
- Музыки в черновике нет (нужна лицензия — подберём к финалу).
- Записи: Playwright пишет веб-версию в `demo/public/footage/` (не в git): телефон — вид 400×866, ровно как рамка
  в кадре (запись идёт в левый верхний угол холста — обрезаем `crop=400:866:0:0`), ноутбук — 1440×900.

## Проверка
- `npx remotion render` собирает `demo/out/draft.mp4` без ошибок; ffprobe: 1920×1080, 30 к/с, длина ≤ 2:55, есть звук.
- Кадры-снимки из каждой сцены (ffmpeg) — глазами: стиль Noir, текст не вылезает, DRAFT виден, плашки моделей
  подписаны там, где модель работает; ни одного кадра демо-рендера под подписью модели.
- `npm run final` без записей падает со списком недостающих файлов.
