# Judges' Version Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A judge on a laptop reaches the try-on in one click, sees what to try and which Meta model does each step, and the README describes everything built so far (spec: `docs/spec-judges.md`).

**Architecture:** A demo style profile in `@twin/shared` next to the quiz; the login screen's demo button fills it and opens Try on; a desktop-only judge panel rendered by `AppFrame` beside the 440 px app column, fed by one data module; README rewritten in place.

**Tech Stack:** Expo Router (React Native + web), TypeScript, vitest (server package runs shared tests), Noir theme tokens.
