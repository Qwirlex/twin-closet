# Спека: любимая вещь — замер сантиметром (без ключа)

План — PLAN.md §1.2 В, п. 3: «самый надёжный способ подбора — сравнение с вещью, которая сидит идеально».
Пользователь 29.10: «начинай с 1-го и так пока всё не сделаешь».

## Что есть сейчас

- Посадка сравнивает новую вещь с любимой того же вида («Next to your black jeans: 3 cm tighter in the waist…»),
  но любимая вещь одна и задана в демо (чёрные джинсы, `favorite: true`, готовые замеры).
- У вещей шкафа нет своего экрана: нельзя ни отметить «сидит идеально», ни ввести замеры.
- Замер по фото рядом с листом A4 (SAM 3.1) — с ключом; сантиметр работает уже сейчас.

## Что делаем

### 1. Расчёт — `packages/shared/src/fit.ts`
- `TAPE_ZONES(kind)` — что мерить у вещи этого вида, плашмя: брюки и юбки — пояс, бёдра, бедро (поперёк),
  длина по внутреннему шву; верх и верхняя одежда — грудь (от подмышки до подмышки); платье — грудь, талия, бёдра.
- `garmentFitFromTape(kind, flat, cut, stretch)` → `{ fit, errors }`: поперечные замеры плашмя × 2 = обхват
  (как в таблицах размеров), длина по шву — как есть. Вне разумных пределов (`TAPE_LIMITS`, плашмя: пояс 25–80 см,
  бёдра 30–90, бедро 15–50, грудь 35–90, по шву 50–100) — зона в `errors`, вещь не сохраняется.
  Нет ни одной зоны — `fit: null`. Источник `source: 'tape'`, размер `'Yours'`.

### 2. Хранение — документ шкафа (`app/src/lib/store.tsx`)
- `measured: Record<id, GarmentFit>` — свои замеры любой вещи шкафа (и демо, и своей);
  `favoriteByKind: { bottom?: id, top?: id, … }` — любимая вещь на каждый вид (одна: отметил другую — первая перестала).
- В шкафу вещь получает `fit` из `measured` и `favorite` из `favoriteByKind` (если для вида выбор не делали —
  как в демо). Синхронизируется с телефоном, как весь шкаф. Чистка при чтении: только известные зоны и числа.

### 3. Экран вещи — `/piece/[id]`
- Открывается по нажатию на вещь в Closet.
- Фото, название, подпись. Переключатель **«Fits me perfectly»** — новые вещи этого вида сравниваются с ней.
- **«Measure it flat»**: подсказка как мерить (разложи, разгладь, мерь прямо поперёк; мы удвоим сами), поля по виду
  вещи в см или дюймах (та же настройка, что в замерах тела), крой (slim … oversize) и «stretchy». Сохранить —
  вещь становится любимой. Ошибка — у поля, с понятным диапазоном.
- Строка «Measure from a photo next to an A4 sheet — SAM 3.1, once the Meta key is connected» — честно, без кнопки.
- Обувь и аксессуары: замеров нет, только «Fits me perfectly» не показываем (сравнивать нечего).

### 4. Посадка на примерке
- Если любимой вещи этого вида с замерами нет — под выводом ссылка «Measure a pair that fits you perfectly» → Closet.

## Проверка
- Тесты (`server/test/fit.test.ts`): удвоение обхватов, длина как есть; диапазоны → `errors`; пусто → `fit: null`;
  верх — только грудь; `fitReport` с любимой вещью из сантиметра даёт сравнение «N cm tighter/roomier».
- Браузер (телефон 390 px): Closet → вещь → замеры → сохранить → на примерке джинсов сравнение с этой вещью;
  «Fits me perfectly» у другой пары снимает отметку с первой; дюймы ↔ см.
