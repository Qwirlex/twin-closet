# Спека: модно, а не базово — выжимка трендов (без ключа)

План — PLAN.md §1.2 Д. Пользователь 29.10: «без ключа делай по порядку всё, спека → план → реализация, с проверкой».

## Что есть сейчас

- Справочник 59 стилей и профиль стиля (`packages/shared/src/style.ts`); `stylePrompt` уже содержит правило
  «без скучной базы, в каждом образе живая деталь». Но правило только в тексте для модели: никто не проверяет,
  что образ не «белая футболка + джинсы + кеды».
- Сборка образов `buildLooks` (`server/src/models/spark.ts`) готова как задача Muse Spark, но ни одна задача сервера
  её ещё не вызывает (ждёт ключ). Тренды нигде не учитываются.
- В «Looks» — «Saved» и «Ideas from your closet» на демо-образах.

## Цель

Образы и Twin знают, что носят этой осенью-зимой, предлагают тренд под стиль человека и не скатываются в базу.
Человек видит тренды сезона и какие его вещи уже в тренде.

## 1. Выжимка трендов — `packages/shared/src/trends.ts`

```ts
type TrendKind = 'silhouette' | 'colour' | 'piece' | 'pattern' | 'texture' | 'styling'
interface Trend { id; name; kind; line; styles: StyleId[]; keywords: string[]; who: 'men' | 'women' | 'all' }
interface TrendDigest { season: string; region: string; updatedAt: string; source: 'curated' | 'spark'; trends: Trend[]; sources: { name; url }[] }
```

- **`CURATED_TRENDS`** — выжимка осень-зима 2026 (Европа), 14 трендов, пересказ своими словами по обзорам
  GQ UK, L’Officiel, Harper’s Bazaar, Who What Wear, Glamour (октябрь 2026; ссылки в `sources`, текст не копируем):
  военные куртки, клетка «по-нарядному», один красный акцент, жёлтый, «шумный» трикотаж (фэр-айл, косы, полоска),
  регбийка, длинный узкий силуэт вместо мешковатого, богатые фактуры (вельвет, жаккард, замша, искусственный мех),
  небрежный пиджак, вестерн-детали, узкая плоская обувь, капюшоны и шарфы, фиолетовый и слива, заниженная талия.
  У каждого: одна строка «как носить», стили из справочника, слова для поиска по вещам шкафа, для кого.
- **`cleanDigest(raw)`** — как `cleanStyle`: из ответа модели берём только валидное (вид из списка, стили только
  из справочника, не больше 16 трендов, строки обрезаны, слова — нижний регистр). Пустой результат → `null`.
- **`trendsFor(digest, profile, who)`** — тренды для человека: сначала те, что совпадают со стилями профиля
  (по весам), тренды из «избегаю» — нет; для мужского/женского опроса — свои и общие.
- **`trendHits(text, digest)`** — какие тренды есть в вещи (название, подпись, ткань, цвет): по целым словам,
  без учёта регистра. «Olive bomber · Nylon · Relaxed» → «Military jackets».
- **`liveDetail(pieces, digest)`** — есть ли в образе живая деталь, и какая: тренд в одной из вещей → его название;
  верхняя одежда поверх → «layers»; цвет не из базовых (не белый/чёрный/серый/синий/бежевый/деним) → «colour accent»;
  фактурная ткань (замша, вельвет, кожа, шерсть букле…) → «texture». Ничего — `null` (это «скучная база»).
- **`trendPrompt(digest, profile, who)`** — 6 трендов под человека строками «Name — how to wear» и правило:
  «в образе 1–2 тренда, только если в стиле человека; тренд не навязываем».

## 2. Сервер

- Задача **`trendDigest`** (`server/src/models/spark.ts`): Muse Spark + веб-поиск по стране, строгая JSON-схема,
  в промпте — список id стилей справочника и правило «пересказывай своими словами, не копируй тексты».
- **`server/src/trends.ts`**: выжимка на страну и неделю (ISO), в кэше хранилища. Нет ключа или ошибка модели →
  `CURATED_TRENDS` (честно `source: 'curated'`). Ключ есть и выжимке больше 7 дней → свежая в фоне, ответ сразу
  из кэша (одна на страну за раз). Расход: одна задача Spark на страну в неделю.
- **`GET /trends?country=IE`** — выжимка (страна — две буквы, иначе IE).
- **Сборка образов**: `looksBrief(profile, digest, who)` = `stylePrompt` + `trendPrompt` — то, что уходит в `buildLooks`;
  в `buildLooks.system` правило про живую деталь и тренды. Ответ модели проверяется `liveDetail`: образ без
  живой детали помечается (`plain: true`), приложение показывает его последним. Вызов `buildLooks` в задаче
  появится с ключом — функция и проверка готовы и покрыты тестами.
- **Twin**: инструмент `get_trends` (тренды под человека), в правилах — «предлагай тренд, если в стиле».

## 3. Приложение

- **Looks → третья вкладка «Trending»**: «Autumn/Winter 2026 · Europe», карточки трендов под человека
  (сначала «For your style»): название, строка «как носить», **«You own: Olive bomber»** (вещи шкафа по `trendHits`)
  или «Not in your closet yet». Кнопка **«Style it with Twin»** → чат Twin с готовым вопросом
  «Build me an outfit around military jackets». Внизу мелко: источник (curated / weekly search by Muse Spark) и дата.
- **Примерка (Result)**: строка «On trend · Military jackets», если в образе есть тренд (рядом с «In your style»).
- Выжимка грузится с сервера (`GET /trends`), без сервера — `CURATED_TRENDS` из shared: экран не пустеет.

## Проверка

- Тесты (`server/test/trends.test.ts`):
  - в `CURATED_TRENDS` 12–16 трендов, у всех валидные стили и непустые слова, id уникальны;
  - `cleanDigest` отбрасывает чужие стили и виды, обрезает лишнее, на мусоре — `null`;
  - `trendsFor`: профиль Military → «Military jackets» первым; тренды «избегаю» не приходят;
  - `trendHits` по демо-вещам: бомбер → Military jackets, худи → Hoods and scarves; «redwood» не даёт «red»;
  - `liveDetail`: белая футболка + синие джинсы + белые кеды → `null`; + оливковый бомбер → не `null`;
  - `looksBrief` содержит стиль и тренды; `GET /trends` без ключа → curated; кэш на неделю — вторая выжимка
    не запрашивается (подменённая модель вызывается один раз).
- В браузере: Looks → Trending (тренды, «You own», переход в Twin с вопросом), на примерке «On trend · …»,
  телефон 390 px и ноутбук с панелью судьи.
- `npm run typecheck`, все тесты сервера.
