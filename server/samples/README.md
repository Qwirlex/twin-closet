# Готовые видео для судей

Кнопка «Use sample video» в приложении берёт файл отсюда. Результат первого прогона кэшируется,
поэтому судьи не тратят кредиты Meta на одно и то же.

| Файл | Что это |
|---|---|
| `closet.mp4` (или `.mov`) | 20–30 секунд вдоль шкафа на вешалках, дневной свет |
| `body.mp4` (или `.mov`) | 6–8 секунд поворота на 360°, ступни в кадре |
| `item.jpg` (или `.png`, `.webp`) | скриншот вещи из магазина |

Файлы не попадают в git (большие и личные). На сервер для судей копируются вручную.
